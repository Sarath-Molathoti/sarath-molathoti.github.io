Fine-Tuning GPT-2 Model for Text Generation

In this post, we will walk through the process of fine-tuning the GPT-2 Medium model on a custom dataset. This tutorial explains each step of the code and how it contributes to training the model effectively.

1. Installing Required Libraries

First, we install the necessary libraries for working with the GPT-2 model and datasets. 

!pip install transformers datasets torch evaluate

2. Hugging Face CLI Login

Login to Hugging Face to access datasets and models.

!huggingface-cli login

3. Loading Model and Tokenizer

Here, we load the GPT-2 Medium model and its corresponding tokenizer. 

from transformers import AutoTokenizer, AutoModelForCausalLM, Trainer, TrainingArguments
from datasets import load_dataset
import torch
from google.colab import files

model_name = "gpt2-medium"
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

4. Uploading and Preparing the Dataset

Upload your JSON file and prepare it for training.

uploaded = files.upload()
file_name = list(uploaded.keys())[0]

def process_text(examples):
    return {
        'text': examples["text"]
    }

dataset = load_dataset("json", data_files=file_name, split="train").map(process_text)

5. Tokenizing the Dataset

Tokenize the dataset to prepare it for training.

def tokenize_function(examples):
    tokenized = tokenizer(
        examples["text"],
        max_length=512,
        padding="max_length",
        truncation=True,
        return_tensors="np",
    )
    tokenized["labels"] = tokenized["input_ids"]
    return tokenized

tokenized_dataset = dataset.map(tokenize_function, batched=True)

6. Setting Up Training Arguments

Configure the training parameters for the GPT-2 model.

training_args = TrainingArguments(
    output_dir="./results",
    learning_rate=2e-5,
    per_device_train_batch_size=4,
    per_device_eval_batch_size=4,
    num_train_epochs=15,
    weight_decay=0.01,
    evaluation_strategy="no",
    save_strategy="epoch",
    gradient_checkpointing=False,
    fp16=False,
    dataloader_pin_memory=False,
    report_to="none",
)

7. Initializing and Training the Model

Load the GPT-2 model and start training with the prepared dataset. 

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.float32,
    device_map="auto",
)

model.config.pad_token_id = tokenizer.pad_token_id
model.config.additive_attention_mask = True

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
    tokenizer=tokenizer,
)

trainer.train()

8. Testing the Model

Generate text using the trained model with a sample input.

def test_model(sample_question):
    inputs = tokenizer(sample_question, return_tensors="pt", padding=True, truncation=True).to("cuda")
    outputs = model.generate(**inputs, max_length=200)
    response = tokenizer.decode(outputs[0], skip_special_tokens=True)
    print("IMS Bot:", response)

test_model("What is the event date of BEL Foundation Day?")

9. Saving the Model

Save the trained model and tokenizer for future use.

model.save_pretrained("./trained_model")
tokenizer.save_pretrained("./trained_model")

Conclusion

Following these steps, we can fine-tune the GPT-2 Medium model for custom text generation tasks. This includes installing libraries, preparing the dataset, training the model, and testing it with custom prompts. The trained model can be used for various applications like chatbots, content generation, and more.
